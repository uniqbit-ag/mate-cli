The brief

A CLI that keeps a product's code apart from the AI's plans, specs and notes, links the two, and guards against leaks. It should feel like a dependable buddy: friendly, trustworthy, tidy, quiet.

Final design

Split Pane

One solid pane of finished work, a stack of notes, and a clear gutter between them.

  • The pane is the product's code, the notes are the AI's studio notebook, the gutter is the boundary
  • Looks like a split terminal window, so it feels native where the tool lives
  • Built on a 16 × 16 grid: converts to ANSI and ASCII art one square per character
