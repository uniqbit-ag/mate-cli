title: Your First Agent Session
description: Install Mate, link a companion, and launch Claude Code or OpenCode with your project context.
---

## Audience

Developers who want to try Mate on one of their repositories and already use
Claude Code or OpenCode.

## Goal

Start an agent in your working repository with the companion's instructions,
skills, and capabilities already in place.

## Steps

<Steps>
<Step>

### Install the CLI

Mate is published to npm and requires Node.js 24.

```sh
npm install -g @uniqbit/mate
```

</Step>
<Step>

### Install core requirements

Run the installer from the repository you want the agent to edit:

```sh
cd /path/to/working-repo
mate install
```

No companion is needed yet. This verifies Mate's core runtime.

</Step>
<Step>

### Link a companion

```sh
mate companion link
```

The link wizard runs in your terminal. Select a registered companion, paste a
local companion path, or clone one from Git. Mate writes the link to a local,
git-excluded `.mate/` directory and installs the requirements the companion
selects.

</Step>
<Step>

### Check the context

```sh
mate doctor
```

The reported state should be `linked-working-repository`, with the companion
path and selected capabilities listed.

</Step>
<Step>

### Launch an agent

```sh
mate claude
# or
mate opencode
```

The companion's allowed agents list must include the agent you launch.

</Step>
</Steps>

## Outcome

The agent runs in your working repository with the companion's guidance,
skills, and capabilities loaded. The link stays on your machine and is never
committed to the working repository. From now on, `mate claude` or
`mate opencode` is the only command you need. Each launch syncs the companion
again, so its updates reach your next session.
